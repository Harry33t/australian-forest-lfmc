# Australian Forest LFMC — web demo

Interactive demo for live fuel moisture content (LFMC) of Australian forests.
Stack: **Vite + React + TypeScript + deck.gl + MapLibre**.

## Highlights
- **3D map** (deck.gl): each field-measured LFMC site is a 3D column — **colour = moisture
  estimate, height = model uncertainty**. Rotate / zoom / hover; switch colour by LFMC,
  uncertainty, or vegetation type.
- **Cross-region transfer matrix** (interactive): R² when a model trained on one IBRA bioregion
  is tested on another.
- **Conformal calibration** curve + per-pixel confidence-band explanation.
- LFMC distribution by vegetation type, and a within-site vs leave-site-out comparison.

## Run
```bash
cd web
npm install --legacy-peer-deps
npm run dev                       # http://localhost:5173
npm run build && npm run preview  # production build preview
```

## Data
`public/data/*.json` is generated by `python ../src/export_web.py` (sites / transfer matrix /
calibration / summary). The Australia outline `australia.json` is dissolved & simplified from IBRA7.

## Structure
```
src/App.tsx                page assembly + data loading
src/components/LfmcMap     deck.gl 3D columns + MapLibre basemap + controls / legend / tooltip
src/components/LoroMatrix  cross-region transfer matrix (SVG)
src/components/Calibration conformal calibration curve (SVG)
src/components/DistChart   LFMC distribution by vegetation type (SVG)
src/lib/color.ts           colour scales
```
